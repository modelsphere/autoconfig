autoconfig 怎么和 openresty / CART / monitor 协作

autoconfig 发现后端，自动给 openresty、CART、monitor 各写一份配置。openresty / CART 由 reload sidecar 收 SIGHUP 热重载；monitor 每 60s 自动热加载 monitor.conf，无需 sidecar。实线 = 配置流，虚线 = 请求 / 健康流。
