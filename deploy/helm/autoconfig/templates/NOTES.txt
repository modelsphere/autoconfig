创建一个 ModelRoute(一个模型一条),controller 会自动:
  发现后端 → 写 CART 的 workers(cart-config)+ openresty 的 peers(openresty-conf,CART 优先 + 后端兜底)。

  kubectl apply -f - <<'EOF'
  apiVersion: routing.gpucluster.io/v1alpha1
  kind: ModelRoute
  metadata: { name: glm-5.1-fp8, namespace: glm }
  spec:
    discovery: { service: glm-leader, port: 8050 }   # 或 selector
    cart: { service: cart-glm, port: 8071, outputConfigMap: glm/cart-config,
            baseConfigRef: { name: base-cart, key: config.base.yaml }, maxLoad: 20 }
    openresty:
      route: glm
      listen: 18083
      outputConfigMap: openresty/openresty-conf
      sources: [{ use: cart, priority: 1, maxConcurrency: 180 }, { use: backend, priority: 0 }]
  EOF

查看状态(发现了几个后端 / CART / ready):
  kubectl get modelroutes -A     # 或 kubectl get mr -A

⚠️ 卸载顺序:先删 ModelRoute,再 helm uninstall。
  ModelRoute 带 finalizer(routing.gpucluster.io/cleanup),要 controller 在跑才能摘。
  若先 helm uninstall(删了 controller)再删 ModelRoute / namespace,ModelRoute 会卡住、
  拖住 namespace/CRD 删除。正确顺序:
    kubectl delete mr --all -A          # 1) 先删所有 ModelRoute(controller 摘 finalizer)
    helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}   # 2) 再卸载
  已卡住的补救:kubectl patch mr <n> -n <ns> --type=merge -p '{"metadata":{"finalizers":[]}}'
